Design system

A refined, neutral foundation for the PlatformOps admin platform. Lighter surfaces, navy held in reserve for moments that matter — primary actions, focus, selection, brand. Color earns its place: status is colored, decoration isn't.

01Principles

01 / 04

Surface over decoration

Backgrounds carry the calm. Borders are hairline, never heavy. Shadows are felt, not seen. Whitespace does the layout work that bold lines used to.

02 / 04

Navy held in reserve

Brand color is a punctuation mark, not a paragraph. Reserved for primary buttons, selected nav, focus rings, and the logo. Everywhere else, ink and lines do the work.

03 / 04

Status is the only loud color

Green, amber, red, and terracotta exist to signal state — never to brighten a page. A pill is a statement: this row is failing, this job is live.

04 / 04

Tables are the exception

For lists of rich entities, lead with cards. For lists of records, use refined tables with monospace IDs and pill status. Either way, the row tells a story before you read the columns.

03Typography

A pairing of Fraunces (variable serif, display only) and Geist (engineered sans, body & UI), with JetBrains Mono for IDs, code, and technical metadata. Fraunces gives the platform warmth that "data infrastructure" usually lacks — used at large sizes only, never below 20px.

10Do & don't

Do
Inline drawers for editing. Slide in from the right, keep the list visible behind. Context survives the edit.
Don't
Full-screen modal for two fields. The current pattern dims the whole page to ask a yes/no question.
Do
Show empty states. A list with zero items is an invitation, not a bug. Render a guide, not a blank table header.
Don't
Render a header row with no body. The user sees columns and assumes the page is broken.
Do
Search and filter visible by default. Above the table, not buried in a modal. Filter chips show what's currently applied.
Don't
Hide filters behind a button on a list page. Users shouldn't have to open a dialog to narrow a list of ten things.
Do
Status as a pill, in its own column. Scanning a list of 50 jobs takes two seconds if status is a colored chip — twenty if it's text.
Don't
"Success" / "Failed" as plain text mixed into a name column. Status is structural, not narrative.
