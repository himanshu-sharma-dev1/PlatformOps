# Selected-page functional parity: authoritative mapping

Status: source audit, 2026-08-21. Scope is the agreed MVP pages only:
Clusters, Config, Diagnostics, Monitoring, Performance, Users, and
Observability. This is a function-to-function map, not a percentage-complete
score. PlatformOps source is current; `/root/cPlatform` is a read-only
behavioral reference.

## Reading this matrix

`/api/*` is the PlatformOps native contract. `/PlatformIO/*` is a compatibility
contract that preserves cPlatform action names/payloads; in Monitoring it
delegates to the optional GlitchTip integration. A route being present is not
runtime proof.

For compactness, `views.py`/`urls.py` in the cPlatform column mean
`/root/cPlatform/cPlatform/cPlatformIO/views.py` and
`/root/cPlatform/cPlatform/cPlatformIO/urls.py`; filename-only PlatformOps
pointers mean the `apps/api/platformops/routers/` file named in that row.

Evidence labels:

- **Contract proven** — cPlatform route/view/helper and the corresponding
  current contract are traced in source; this does not assert a live call.
- **Implemented** — current UI/API/backend path is present and its behavior is
  traceable in source.
- **Runtime-tested** — the dated isolated MVP evidence exercised this path;
  it is historical evidence, not a claim about this checkout's current test
  run.
- **Unverified** — no current runtime proof, no direct counterpart, or the
  visible action is only a stub/uncertain path. The gap column states which.

Historical evidence is recorded separately in the
[historical execution section](mvp-status.md#historical-execution--2026-08-1011),
which records the isolated Cluster → Node → Service sequence, deployment, live
status/discovery/logs, and Config validation/snapshot/timeline; the prior
isolated handoff also recorded a containerized API suite of 24 passing tests.
This audit did not rerun pytest and makes no current pytest-success claim.

## Residual verification risks

- No current pytest success is claimed; the 24-pass result is historical
  isolated evidence only. Host dependency limitations and the dated runtime
  boundary remain documented in the [fresh checks](mvp-status.md#fresh-checks--2026-08-21)
  and [exact known limitations](mvp-status.md#exact-known-limitations) sections.
- Prometheus-backed node/service/process fields can be zero or empty when
  Prometheus/exporters are unavailable. Service log-error, queue-depth,
  latency-p95, and the current `error_rate_series` query are placeholders or
  non-error telemetry as described in §5.
- Loki history/backfill requires collectors and indexed data; live logs are
  bounded HTTP tails, not streaming.
- Remote SSH/Ansible, cloud VM launch/teardown, external GlitchTip, mail
  delivery, and configured LLM diagnostics require isolated or external
  runtime verification before stronger evidence labels are warranted.
- The matrix covers the seven selected pages and their adjacent native
  contracts; Advanced pages, exhaustive catalog edge cases, and visual
  similarity are intentionally outside this MVP document.
